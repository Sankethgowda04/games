# Game Collection

This folder contains the current game project collection.

## Current Project

### Starter Game
A simple arcade dodge game built with HTML5 Canvas.

- **Location:** `starter-game/`
- **Controls:** Arrow keys
- **Objective:** Dodge enemies and survive as long as possible

## Run

Open the game directly in a browser:

```text
starter-game/index.html
```

Or open the main project launcher:

```text
../launch.html
```
